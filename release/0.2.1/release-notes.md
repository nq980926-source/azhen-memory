# 阿斟 Memory 0.2.1

首个统一 GitHub Release 构建。Windows、macOS 和 Android 使用相同的
`main.js`、`manifest.json` 与 `styles.css`。

## 安装

下载 `azhen-memory-0.2.1.zip`，解压后将三个插件文件放入：

```text
<vault>/.obsidian/plugins/azhen-memory/
```

重新加载或启用插件。升级时请保留原有的 `data.json`。

## 安全

- Bearer Token 只保存在 Obsidian SecretStorage。
- Release 不包含服务器地址、Assistant ID、Token、API Key 或 Memory 正文。
- 请自行填写你现有的阿斟 Memory HTTPS 服务配置。
